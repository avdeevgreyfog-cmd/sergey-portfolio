# Portfolio / editorial workspace direction

Personal developer portfolio for Sergey Avdeev. Audience: prospective clients who need to understand the offer, inspect real work, and discuss a project.

## Design contract
- Thesis: business task → product logic → interface → release.
- Homepage signature: restrained dark editorial layout with a single cinematic workspace photograph, large typography and thin technical details.
- Palette: deep ink #050a10, navy surfaces, porcelain text, slate secondary text, ice-blue accent.
- Typography: self-hosted Manrope variable for headings, body and interface text. Cyrillic and Latin subsets are already licensed and stored in the repository.
- Grid: maximum 1200px with asymmetric hero and services. Mobile collapses to a single readable column.
- Homepage projects policy: cases stay in Works. The homepage has a large Works gateway rather than case cards.
- Imagery: workspace art is decorative generated imagery, never presented as evidence of a real project. Project cases continue to use real project UI or explicitly labelled demo data.
- Motion: small hover and navigation transitions only; reduced-motion remains supported.
